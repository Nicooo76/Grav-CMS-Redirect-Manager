# Feature checklist

Independent final audit of Redirect Manager 1.0.0 against the product owner's brief, point by point. Rule of the brief: a point without a test is not implemented. So every row names the test that proves it. A test only counts when it asserts the behaviour, not merely runs the code. Where a test covers only part of a requirement, the row is `partial` and says what is missing.

Audit date: 2026-09-29. The audit started on commit `1526d23` plus an uncommitted working tree. During the audit the parallel agent committed its bug fixes as `275530f` ("Fix bugs found by the Playwright suite", 18:58). Results below say which state they were measured on: **HEAD `275530f`** for the final unit, PHPStan, coverage and Playwright runs, the older state for the release and integration runs. Nothing in this audit changed code or tests.

## How to read this file

Status values: `done`, `partial`, `not possible in Grav 2`, `missing`. `not possible in Grav 2` means the literal requirement cannot be met on Grav 2.2.2 or Admin 2 2.1.25. The row then says what was built instead and whether that substitute is tested.

Path prefixes in the Evidence column:

| Prefix | Directory | Runner |
|---|---|---|
| `U:` | `tests/Unit/` | PHPUnit 11.5, `--testsuite unit` (Grav stand-ins, no server) |
| `I:` | `tests/Integration/` | PHPUnit 11.5, `--testsuite integration` (real Grav 2.2.2, real HTTP and CLI) |
| `P:` | `tests/ui/specs/` | Playwright against Admin 2. The title in quotes is the test title. |
| `V:` | `admin2/src/` | Vitest (`*.test.ts`) |
| `M:` | `tests/Unit/Matching/fixtures/matcher-cases.php` | case name, run by `U:Matching/MatcherTableTest::testCase` |

Method names are written in full (`testFoo`). A file path without a method means the whole file is the evidence (documents).
